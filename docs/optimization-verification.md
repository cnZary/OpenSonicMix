# 本轮优化验证

本轮保留窗口尺寸、布局、主题及 DPI 行为；保留电平刷新周期、平滑速度、峰值保持时间和设备读回验证。基准版本为 `fd8fbfa6d6f9440e133a52b738a88300c7bfcb8d`。

## 自动回归

```powershell
dotnet build SonicCubePanel.slnx -c Release --no-restore
dotnet test SonicCubePanel.slnx -c Release --no-build --no-restore
dotnet publish SonicCube.Tray/SonicCube.Tray.csproj -c Release --no-restore -o out/optimization-verification/tray-publish
```

最终 Release 全量测试 **166 项通过，0 失败、0 跳过**（Protocol/Shared/Tray 63 项，Panel 103 项）。原有 94 项测试保留，包括电平动画的 60/144/240 Hz 回归。新增覆盖：

- 慢设备（100/200/300 ms）下每地址仅保留正在执行值和最新待发送值；最终值验证、不同地址独立合并、重置/算法切换隔断合并、连续开关保序。
- 命令排队超时、连接取消、退出清理；命名管道阻塞写入、断连、重连与旧版本快照/状态丢弃。
- 驱动异步完成、同步回调、发送中关闭、延迟释放、释放重试失败、回调代次隔离、会话等待表及快照独立复制。
- 推子拖动/滚轮/键盘显示一致、失败重试、较新输入保护、捕获丢失/禁用/卸载恢复、BYPASS 禁用编辑器、自动语言恢复。
- 设置文件写入失败不发布新配置，界面回滚并允许重试；断连期间保留最后确认参数。

## Global EQ 绘制对比

复现命令及测量细节见 [EQ 基准说明](../tools/eq-benchmark/README.md)。每种路径预热 8,000 次，10 轮交错测量，每轮 12,000 次，以下为各轮中位数。

| 路径 | 修改前耗时 | 修改后耗时 | 修改前分配 | 修改后分配 |
|---|---:|---:|---:|---:|
| 不变快照 | 159.76 µs | 101.86 µs | 44,600 B | 25,568 B |
| 悬停 | 163.45 µs | 104.08 µs | 44,552 B | 25,520 B |
| 参数拖动 | 163.23 µs | 161.61 µs | 45,256.68 B | 45,256.68 B |

不变快照及悬停路径的托管绘制耗时下降约 36%，分配下降约 43%。拖动前后分配不变，耗时差异处于重复测量波动范围，未见可测回退。

18 组像素比较全部一致：两种画布尺寸、三种已有 DPI、三种 EQ 状态。DPI 仅用于验证原输出未变，本轮未添加布局或 DPI 适配。

该基准测量 WPF `OnRender` 的托管绘制记录与线程分配，不代表 GPU、合成器、整程序 CPU 或真实帧率。强制绘制也未计入相同值短路减少重绘次数的额外收益。

| 会话 | 握手 | 写入读回中位数 | 最慢写入读回 |

| 2 | 12.47 ms | 79.84 ms | 91.68 ms |

读回时间包含原有 70 ms 设备等待。此次真机验证覆盖重复打开关闭、原值写入和读回；断连与驱动故障恢复通过模拟测试验证，未执行真机拔插或长时间浸泡测试。可复现工具见 [真机检查说明](../tools/device-readback-smoke/README.md)。
